Data Science · Thesis

Skill-Based Salary Prediction for Data Roles in the Philippines

Nov 2024 – Aug 2025

Undergraduate thesis, Mapúa University · Project Lead, Programmer

  • Collected Philippine data job postings from Indeed with Apify over four months (Nov 2024 – Mar 2025), then deduplicated, filtered salaries and normalized titles down to 1,057 salaried postings.
  • Used GPT-4o-mini to extract and standardize soft and technical skills from unstructured job descriptions, yielding 720 distinct skills.
  • Grouped 43 job titles into 6 role families with Sentence-BERT embeddings and K-Means, testing k with silhouette scores.
  • Compared Linear Regression, Random Forest, LightGBM and XGBoost for predicting min and max salary, with grid search and 5-fold cross-validation. XGBoost did best on the held-out test set.
  • Converted model feature importance into estimated peso values per skill to show which skills go with higher-paying roles.

Data Science · Thesis · Case study

What is a data skill worth in the Philippines?

We collected four months of Indeed job postings, used an LLM to pull out the skills each one asks for, and trained models to estimate salaries. Then we turned what the model learned into a peso value for each skill.

Undergraduate thesis, Mapúa University · Project Lead, Programmer · with Paul Angelo Z. Perez · Nov 2024 – Aug 2025

Salaried postings modeled
1,057
Distinct skills extracted
720
Role families
6
Best test MAE (XGBoost)
₱17K
[ ]:

01 · collect

Four months of Indeed postings, pulled daily

Why Apify: a scheduled actor returns Indeed's structured fields every day, so we didn't need a scraper that breaks whenever the page layout changes.

[ ]:

02 · extract

An LLM reads every description and lists the skills

Why not keyword matching: postings write the same skill a dozen ways ("MS Excel", "advanced Excel", "Excel/Sheets"). GPT-4o-mini, at temperature 0.3, maps each one to a single standard name based on the O*NET taxonomy.

→ Technical skills

  • Microsoft Excel
  • SQL
  • Business Intelligence Tools
  • Project Management Software
  • Data Visualization

→ Soft skills

  • Communication Skills
  • Teamwork

Dashed: the model added these even though the posting never mentions them. Communication appears in 99% of postings, partly for this reason.

MS Excel→Microsoft Excel

Strong SQL knowledge→SQL

Good verbal communication→Communication Skills

[ ]:

03 · clean

From 1,318 extracted postings to 1,057 we could trust

Before this: we removed duplicates by link and by description text, kept only 80 data-related titles, and dropped skills that appeared just once. Here: every posting that remains has a monthly salary we can compare.

[ ]:

04 · group

43 job titles, 6 role families

Why cluster: many titles had only a handful of postings, too few to learn a salary from. We embedded each title together with its skills using Sentence-BERT (all-MiniLM-L6-v2), ran K-Means for k = 2–14, chose k by silhouette score, and assigned each title to its majority cluster.

[ ]:

05 · model

Four models, one test set they never saw

Features: TF-IDF weights for the skills, plus role family, location, job type and a seniority level parsed from the title. A Random Forest ranked them, and we kept the top 150 after checking validation R² at every step of 10. Tuning: a 3-fold grid search inside a 5-fold cross-validation, both predicting min and max salary.

Reading it honestly: XGBoost is off by about ₱17K on max salary, and an R² of 0.44 means postings explain less than half of the pay spread. Company, years of experience and negotiation aren't in the data.

[ ]:

06 · value

Turning importance into pesos

How: we averaged XGBoost's feature importance across the min and max models, min-max scaled it, and multiplied by the average gap between posted max and min salary (₱61,102 − ₱44,853 = ₱16,249). The top skill gets the full gap, and every other skill gets a share of it.

99%

of postings ask for communication skills. Ranked by demand, Excel and SQL lead. Ranked by value, niche data-platform skills like enrichment, loading, AWS DMS and Azure lead. What's common isn't what pays.

[ ]:

07 · next

What we'd do differently

01

Check the extraction

Hand-label around 100 postings to measure how often the LLM adds or misses skills, like the inferred soft skills above.

02

Widen the data

Indeed alone, over four months, is one slice of the market. We'd add other job boards and a full year to see seasonality.

03

Add experience

Years required is in most descriptions but wasn't modeled. It's likely the biggest gap between an R² of 0.44 and a useful one.

Skill values reflect what the model relied on, not what causes a raise. Read them as signals, not guarantees.
